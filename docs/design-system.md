# Meety 디자인 시스템

## 컬러

### Slate Navy

Meety의 브랜드 컬러다. 기본 인터랙션 컬러는 `600`을 사용하고 상태에 따라 Hover는
`700`, Pressed는 `800`을 사용한다. 배경에는 `50` 또는 `100`을 사용한다.

| 단계 | HEX       | 용도             |
| ---- | --------- | ---------------- |
| 50   | `#F4F7FA` | 배경 틴트        |
| 100  | `#E6ECF3` | 배경 틴트        |
| 200  | `#CBD8E6` |                  |
| 300  | `#A6BAD1` |                  |
| 400  | `#7A94B5` |                  |
| 500  | `#52739C` |                  |
| 600  | `#2F4C74` | 기본 브랜드 컬러 |
| 700  | `#26405F` | Hover            |
| 800  | `#1F3555` | Pressed          |
| 900  | `#142238` |                  |

### Cool Neutral

브랜드 컬러와 충돌하지 않도록 회색에 파란색을 소량 섞은 Neutral 컬러다.

| 단계 | HEX       |
| ---- | --------- |
| 50   | `#F6F8FA` |
| 100  | `#EEF1F4` |
| 200  | `#E2E6EB` |
| 300  | `#CBD1D8` |
| 400  | `#A3ABB5` |
| 500  | `#6B7685` |
| 600  | `#4A5462` |
| 700  | `#343C47` |
| 800  | `#232A33` |
| 900  | `#161E2B` |

### 상황색

상황색은 본문용 색상과 배경용 색상 각 1개만 사용한다.

| 토큰       | 본문      | 배경      | 용도                                   |
| ---------- | --------- | --------- | -------------------------------------- |
| Success    | `#1F7A4D` | `#E8F4EE` | 회의록 저장 완료, 태스크 배정 완료     |
| Warning    | `#9A6212` | `#FAF1E1` | 담당자 미지정 태스크, 낮은 요약 신뢰도 |
| Danger/REC | `#C0453C` | `#FBEBE9` | 입력 오류, 회의 삭제, 녹취 중 표시     |
| AI Accent  | `#1F6B78` | `#E4F1F3` | AI 코칭, 챗봇, 리포트                  |

## 사용 원칙

- 기본 브랜드 인터랙션은 Slate Navy `600`을 사용한다.
- Hover 상태는 Slate Navy `700`, Pressed 상태는 Slate Navy `800`을 사용한다.
- 연한 브랜드 배경에는 Slate Navy `50` 또는 `100`을 사용한다.
- AI Accent는 AI 코칭, 챗봇, 리포트에만 사용한다.
- 아직 용도가 정해지지 않은 컬러 단계에는 별도의 의미를 부여하지 않는다.
